# Czytanie

PWA для iPad, яка вчить читати польською вголос: 21 авторська вправа від окремих звуків до зв'язного тексту, 63 записи диктора з межами кожного слова. Головне правило — **спершу читаєте самі, потім перевіряєте себе на слух**. Прогрес видно за темпом холодного читання. Ідея й рішення — `idea.md`, правила — `.specify/memory/constitution.md`, специфікація — `specs/001-czytanie/spec.md`.

## Як займатися

П'ять–сім хвилин на день, одна вправа. «Сьогодні» пропонує, яку саме, і раз на тиждень — повторення опанованої.

| Крок | Що робите |
|---|---|
| 0. Холодне читання | Текст прихований до «Почати». Читаєте твір уголос без підготовки, «Готово» — і бачите темп проти цілі (60 / 80 / 100 слів за хвилину для рівнів I / II / III). Холодне — лише перше читання вправи за день; далі це розминка. |
| 1. Правило | Коротке пояснення українською; дотик до прикладу — звук. |
| 2. Гама | Рядок слів: читаєте → «Перевір» → чуєте диктора → торкаєтеся слів, що вийшли інакше (або ← → і `x`). Літери, які тренує вправа, виділено кольором. |
| 3. Що прозвучало? | Звучить слово — вибираєте написання (`Kasia / kasa / kasza`). У вправах 03, 09–21 крок пропущено з поясненням. |
| 4. Миттєве читання | Фраза з'являється на 2 / 1,5 / 1,2 с і зникає; кажете її → «Перевір» → «Так / Ні». Час показу скорочується після двох «Так» поспіль. |
| 5. Разом із диктором | Читаєте одночасно з диктором за підсвіткою слів; швидкість 0,7–1,2×. На рівні III пропонується пропустити, якщо холодний темп уже досяг цілі. |
| 6. На темп | До трьох спроб поспіль, темп кожної поруч. «Ведучий» підсвічує слова з рівним темпом і прискорюється на 10 % після трьох вдалих спроб. «Позначати важкі» — дотик додає слово до важких. |
| 7. Підсумок | «Легко / Важко / Не вийшло», холодний і найкращий темп, точність самоперевірки, нові важкі слова. |

Довге натискання на слово (0,5 с) у кроках 2, 4, 5, 6 показує наголос, у вправі 11 — склади. Дотик до такого слова програє його, але в кроках 2 і 4 лише після «Перевір». Будь-який крок відкривається окремо: «Окремий крок» на картці вправи.

Поза сесією:
- **Важкі слова** — усе, що не вийшло, повертається через 1, 3, 7 і 14 днів; після трьох «Так» на 14 днях слово вивчене.
- **Розрізнення** — «Що прозвучало?» за парами звуків з усіх початих вправ.
- **Прогрес** — графік холодного темпу з лінією цілі, рівні 21 вправи, точність за парами.
- **Слухати текст** (кнопка «Слухати» на картці вправи) — єдиний режим, де звук іде до вашої спроби: для знайомства з текстом.

**Рівні опанування:**
- 0 — сесій ще не було;
- 1 — є холодне читання;
- 2 — темп досягнув цілі, а самоперевірка того дня ≥ 90 %;
- 3 — холодне читання на цільовому темпі щонайменше через 3 дні після першої сесії. За один день рівень 3 недосяжний: це навичка, а не залік.

**Клавіатура:**
- пробіл — «Почати / Готово / Перевір / Показати / пуск»;
- Enter — «Далі»;
- 1 / 2 / 3 — «Так / Ні», варіанти й самооцінка;
- Esc — зупинити звук, а якщо тихо — вийти зі сесії зі збереженням.

Позначити окреме слово в гамі можна лише дотиком.

## Команди

```sh
npm install
npm run dev            # розробка: http://localhost:5173
npm run data           # content/ → public/data/cwiczenia.json + public/audio (з хешем у назві); --report → build/report.md
npm test               # модульні тести (Vitest)
npm run test:e2e       # e2e (Playwright): WebKit iPad Pro 11 у двох орієнтаціях + офлайн і оновлення в Chromium
npm run check          # обидві production-збірки + перевірка секретів, зовнішніх адрес, CSP, шляхів, розміру, текстів автора
npm run preview        # production-збірка dist на http://localhost:4280
npm run deploy         # check + публікація dist на Cloudflare Workers
npm run icons          # перемалювати піктограми
npm run sync-content   # разово скопіювати тексти й аудіо з Krok_po_kroku_2/czytanie у content/ (перезаписує content/)
```

## Збірки й публікація

| Збірка | Команда | Тека | `base` | `start_url` / `scope` | service worker |
|---|---|---|---|---|---|
| Будь-яка адреса (Cloudflare) | `npm run build` | `dist` | `./` | `./` | `./sw.js`, область — тека сторінки |
| GitHub Pages | `npm run build:pages` | `dist-pages` | `/Polish_czytanie/` | `/Polish_czytanie/` | `/Polish_czytanie/sw.js`, область `/Polish_czytanie/` |

- Cloudflare Workers: `wrangler.jsonc` (Worker `polish-czytanie`, статика `./dist`), заголовки й кешування — `public/_headers`. Записи мають хеш у назві й кешуються назавжди, `sw.js`, маніфест і дані — без кешу.
- GitHub Pages: назва репозиторію — `REPO` у `vite.config.ts`.
- Код ще не опубліковано: репозиторій і деплой — окремим рішенням.

**Офлайн:**
- код і тексти завжди в кеші service worker;
- 63 записи (40 МБ) кешуються, коли вправу вперше відкривають, або всі разом кнопкою «Завантажити все аудіо» в налаштуваннях;
- при оновленні програми завантажене аудіо лишається, а старі версії записів видаляються.

**Оновлення:** нова версія чекає, доки ви натиснете «Оновити» в смузі «Доступна нова версія». Перед перезавантаженням записується все незбережене. Прогрес в IndexedDB оновлення не зачіпає.

## Встановлення на iPad (Safari)

Service worker і робота без інтернету потребують HTTPS-адреси (Cloudflare або GitHub Pages). Адреса Mac у локальній мережі відкриється, але без офлайну.

1. Відкрийте адресу в **Safari**.
2. Дочекайтеся, поки сторінка повністю завантажиться.
3. **Поділитися** → **На початковий екран** → «Czytanie» → **Додати**.
4. Відкрийте програму з початкового екрана (без адресного рядка) → «Налаштування» → **Завантажити все аудіо** (40 МБ, один раз).

## Перевірка на iPad

1. **Офлайн:** увімкніть режим польоту, закрийте програму з перемикача програм і відкрийте знову. Мають відкритися «Сьогодні» та будь-яка вправа зі звуком.
2. **Звук слова:** «Вправи» → 07 → «Слухати» → дотик до «Kasia». Має звучати тільки це слово, без початку «kasza».
3. **Сесія 07:**
   - холодне читання → «Готово» показує темп;
   - у гамі до «Перевір» нічого не звучить;
   - після «Перевір» звучить рядок і підсвічується слово.
4. **Миттєве читання:** фраза зникає приблизно через 2 с; після двох «Так» показ стає коротшим (видно «показ 1,6 с»).
5. **Ведучий:** у кроці 6 увімкніть «Ведучий». Підсвітка має йти рівно, без ривків.
6. **Запис себе:** увімкніть у налаштуваннях і дозвольте мікрофон. У гамі після «Перевір» «Я» має програти ваш голос, «Диктор» — запис.
7. **Наступного дня:**
   - «Сьогодні» показує важкі слова з учорашньої сесії;
   - нова сесія тієї ж вправи починається з холодного читання;
   - на графіку «Прогресу» з'являється друга точка.
8. **Копія:** «Налаштування» → «Зберегти копію» → «Зберегти у Файли». Потім «Відновити з копії» → «Об'єднати»: кількість спроб не змінюється.
9. **Орієнтації, Split View, клавіатура:**
   - поверніть iPad і відкрийте програму поруч з іншою — нічого не обрізано;
   - з апаратною клавіатурою сесія проходиться пробілом, Enter і цифрами.
10. **Оновлення:** після публікації нової версії відкрийте програму. Має з'явитися смуга «Доступна нова версія», а після «Оновити» прогрес і завантажене аудіо лишаються.

## Як змінити або додати текст

- **Джерело правди** — `content/teksty/NN-slug.md` у форматі `KONCEPCJA.md` курсу:
  - YAML-шапка;
  - секції `## Gama`, `## Pasaże`, `## Utwór`, `## Uwaga`.
- **Після правки тексту:**
  1. Перегенеруйте аудіо цієї секції скриптом `scripts/tts_czytanie.py` з репозиторію курсу (ElevenLabs, ключ лише в середовищі Mac).
  2. Покладіть `NN-sekcja.mp3` і `.align.json` у `content/audio/`.
  3. Запустіть `npm run data`. Він зупиниться, якщо текст і запис розійшлися хоч на символ.
- **Ваше погодження.** `npm run check` порівнює тексти з `content/SOURCE.md5`, тож змінений текст не пройде перевірку без вашого погодження.
  - Після погодження запишіть новий стан: `node scripts/sync-content.mjs --md5-only`.
  - Розбіжність із текстами курсу в `Krok_po_kroku_2/czytanie` — лише попередження.
