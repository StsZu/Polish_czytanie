# Конституція проєкту «Polish Czytanie»

Постійні правила PWA, яка вчить читати польською. Порушення будь-якого пункту розділу **Non-negotiables** блокує приймання. Ідея й рішення — `idea.md`.

## I. Принципи

1. **Навчає читати, а не слухати.** У кожному тренувальному кроці власна спроба читача йде **перед** звуком диктора. Звук — перевірка. Виняток один: окремий режим «Слухати текст» для знайомства з твором.
2. **Одне явище, три щільності.** Вправа — це гама (слова) → пасажі (фрази) → твір (текст). Структура 21 вправи й самі тексти не змінюються без рішення автора.
3. **Підказка зникає.** Виділення фокусних літер: повне в гамі, бліде в пасажах, жодного у творі. Транслітерації й перекладу в тілі вправи немає. Склади й наголос — лише на дотик.
4. **Чесна мірка.** Опанування рахується за холодним читанням: першою за день спробою твору до будь-якого прослуховування й тренування цієї вправи того ж дня, або читанням незнайомого тексту. Завчений текст не підвищує рівень.
5. **Помилка повертається.** Слово, позначене як помилка, потрапляє в «Важкі слова» й повертається за інтервалами, доки не стане правильним тричі поспіль.
6. **Коротко щодня.** Повна сесія вправи — 5–7 хвилин; кожен крок можна пропустити; програма завжди пропонує, що робити сьогодні.

## II. Обмеження

- React, TypeScript `strict`, Vite. Runtime-залежності: `react`, `react-dom`, `idb`. Будь-яка інша — з обґрунтуванням у `plan.md`.
- Інтерфейс — українською. Польські тексти — лише в області читання та в назвах вправ.
- Жодних мережевих запитів, крім власного origin. Програма не звертається до жодного API. Ключ ElevenLabs існує лише в середовищі Mac для скрипта генерації аудіо.
- Дані користувача — лише IndexedDB на пристрої. Запис голосу живе лише в пам'яті вкладки.
- Джерело текстів — `content/teksty/*.md`. JSON для програми генерується скриптом, руками не правиться.
- Аудіо не перекодовується під час збірки. Нові записи — лише скриптом із таймкодами.
- Хостинг — Cloudflare Workers, статика `dist`. Конфігурація GitHub Pages (`dist-pages`) підтримується в робочому стані.
- Платформа — Safari / iPadOS 17+. Перевірка — WebKit «iPad Pro 11» в обох орієнтаціях.

## III. Пріоритети (при конфлікті — вищий виграє)

1. Правильність польських текстів і звуку (діакритика, відповідність запису й тексту).
2. Навчальна дія: власна спроба → перевірка → повтор.
3. Збереження даних користувача (жодної втрати під час оновлення, імпорту чи помилки запису).
4. Робота без інтернету.
5. Зручність на iPad (дотик, клавіатура, орієнтації).
6. Вигляд.
7. Розмір і швидкість.

## IV. Стандарти якості

| Область | Стандарт |
|---|---|
| Текст читання | 22–30 px (налаштовується), інтерліньяж 1,6–1,8, рядок ≤ 65 символів; контраст ≥ 4,5:1 у світлій і темній схемах |
| Дотик | цілі ≥ 44 × 44 pt; основні кнопки кроку — у нижній третині екрана в портретній орієнтації |
| Клавіатура | усі кроки можна пройти без дотику: пробіл, Enter, 1 / 2 / 3, ← →, Esc; видимий фокус |
| Фрагмент звуку | слово чи фраза звучить від `od − 0,08 с` до `do + 0,08 с`; зупинка ≤ 0,05 с після межі |
| Темп | сл/хв = слова твору / (час від «Почати» до «Готово») × 60; спроби < 5 с або > 300 сл/хв не зберігаються |
| Офлайн | після першого відкриття працюють усі екрани; вправи, чиє аудіо завантажено, — повністю |
| Дані | кожна помилка запису видима, з кнопкою «Спробувати ще»; імпорт перевіряє всю структуру й перелічує кожну проблему |
| Розмір | JS + CSS ≤ 120 КБ gzip (без даних і аудіо) |
| Консоль | 0 помилок у production-збірці під час e2e |
| Тести | `npm run check` і `npm run test:e2e` проходять перед кожним push |

## V. Non-negotiables

1. Жоден крок читання (гама, пасажі, твір на темп, важкі слова, незнайомий текст) не програє звук одиниці до власної спроби читача. Звук без спроби дозволено лише там, де він сам є завданням: «Що прозвучало?» і «Слухати текст».
2. Рівень опанування 3 неможливо отримати за один календарний день.
3. Тексти `content/teksty/*.md` збігаються з авторськими за md5, доки автор не погодив зміну. Нові тексти потрапляють у програму лише після погодження автором.
4. Оновлення програми й імпорт копії не видаляють і не перезаписують спроби та важкі слова без явного підтвердження.
5. У клієнтському коді та збірці немає секретів і зовнішніх адрес (перевіряє `scripts/check.sh`).
6. Кожен запис аудіо звучить синхронно з текстом: межі слів з таймкодів, без ручного зсуву.

## VI. Процес

- Кроки spec-driven: `idea.md` → ця конституція → `specs/001-czytanie/spec.md` → `plan.md` → `tasks.md` → реалізація хвилями → `alignment.md`.
- У кожного завдання є перевірний результат і умова Done. Не більше 3 ітерацій виправлень на завдання; далі — відхилення в `alignment.md`.
- Commit, push, deploy і платна генерація (ElevenLabs) — лише за окремим `ok <дія>`.
